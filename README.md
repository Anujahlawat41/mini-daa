# 2048 Game in Python (Tkinter)

## Overview
This project is a desktop version of the popular **2048 puzzle game**, implemented using **Python’s Tkinter GUI library**.  
Players can use the arrow keys to slide and combine tiles to reach the number **2048**. The game ends when no valid moves remain.

---

## Features
- Fully playable **2048 grid (4x4)** implementation  
- **Responsive arrow key controls** for movement  
- **Dynamic tile colors** based on values  
- **Automatic random tile generation** after each valid move  
- **Game Over detection** when no moves are possible  
- Clean and minimal **Tkinter-based GUI**

---

## Technologies Used
- **Language:** Python 3  
- **Library:** Tkinter (standard GUI library for Python)  
- **Modules:** `random`, `tkinter`
